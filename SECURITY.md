# Security policy

Logyard is currently a release candidate. Security fixes target `main` and the next release candidate.

Report suspected vulnerabilities privately to **shawn@zsumz.com**. Include the affected version or commit, reproduction steps, and the expected impact. Avoid public issues containing exploit details or secrets.

Relevant areas include captured data, redaction and field exclusions, output failure reporting, file ownership, reload, and artifact provenance. Ordinary defects and feature requests belong in the issue tracker.
